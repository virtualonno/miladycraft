# Miladycraft

[Mod catalogue](MODLIST.md) · [Printable catalogue](docs/MODLIST.pdf) · [Changelog](changelogs/CHANGELOG.md)

The catalogue lists the pack's pinned mod versions, author descriptions,
source pages and declared dependencies in both directions. The Markdown is
searchable by mod name or ID; the PDF uses the same captured metadata.

Packwiz's [pack.toml](pack.toml) and verified index define the configured pack.
The catalogue does not claim to be a census of a particular running client.

Contributors: see [Authoring and release documentation](AUTHORING.md).
